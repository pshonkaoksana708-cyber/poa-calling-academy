## 5. Незначительные замечания

1. В проекте есть компонентные fallback-визуалы `image-placeholder`.
   - На проверенных страницах битых изображений не найдено.
   - Сами fallback-компоненты не являются ошибкой.

2. В `public/images` есть неиспользуемые изображения.
   - Они не удалялись, потому что могут быть резервными материалами.

3. Шрифты подключаются через Google Fonts в `styles/globals.css`.
   - Для автономной production-устойчивости можно позже рассмотреть локальное подключение.

4. `sitemap.xml` без заданного `SITE_URL` отдаёт относительные URL.
   - После задания production-домена sitemap будет отдавать абсолютные URL.
